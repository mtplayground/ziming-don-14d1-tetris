# ziming-don-14d1-tetris

## Development

```bash
npm install
npm run dev
```

The development server listens on `0.0.0.0:8080`.

## Validation

```bash
npm test
npm run test:e2e
npm run lint
npm run build
```

## Static Production Build

```bash
npm run build
npm run preview
```

The production build writes static assets to `dist/`. Serve that directory from any static host.
